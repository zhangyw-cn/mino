# Mino Markdown Parity and Status Bar Color Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore Dark Modern status bar colors after the React cutover, lock Markdown preview parity with Vitest for GFM/sanitize/TOC/width chrome, and finish with sample.md smoke.

**Architecture:** No new modules. Fix `StatusBar` Tailwind classes to match the 2026-08-27 Dark Modern contract. Extend existing Vitest suites (`PreviewPane.test.tsx` for StatusBar, `MarkdownViewer.test.tsx` for render parity). Pure helpers (`preprocess`, `preview-width`, `preview-session`, `toc`, `mermaid-block`, `asset-refs`) already carry most pipeline coverage — this plan only adds missing component contracts and a structured code checklist for the rest.

**Tech Stack:** React 19, TypeScript, Vite, Tailwind 4, Vitest, Testing Library, Go embed of `internal/ui/dist`.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-09-21-mino-md-parity-status-bar-design.md`
- Status bar: 22px, background `#181818`, top border `#2b2b2b`, text `#cccccc`; forbid `#007acc` / `#007ACC`
- Width labels: 标宽 / 较宽 / 全宽; key `mino-md-preview-width`; default `wide`
- Fix all in-scope parity gaps in this pass; no new Markdown features
- No Playwright; no backend/catalog/watch semantic changes; no new npm dependencies
- Prefer TDD; commit after each task
- After UI source changes that ship in the binary, run `cd web && npm run build` before claiming embed/smoke done
